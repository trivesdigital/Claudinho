# Claudinho

Carrosséis do Zanellato: use a skill **`/carrossel`** (`.claude/skills/carrossel/SKILL.md`). Ela tem o fluxo completo, as regras de estilo e o formato do roteiro — não é preciso ler o código.

Comando principal: `node carrossel/gerar.js carrossel/carrosseis/<pasta>/roteiro.json` (gera capa + slides + `previa.jpg` + relatório).
Sempre trazer o roteiro para aprovação antes de gerar.
